Build a highly professional, enterprise-grade web application called Nuvora.

This is NOT a generic HR dashboard, warehouse dashboard, ERP template, CRM, or AI chatbot.

It is an **industry-agnostic Business Operations, Administration, Workforce, Intelligence and AI platform** that can be configured for almost any organization — manufacturing, warehouse, logistics, healthcare, education, retail, corporate offices, agriculture, hospitality, professional services, or other industries.

The platform must allow an organization to manage its people, departments, operations, workflows, assets, documents, approvals, performance, KPIs, audits and organizational intelligence from one unified system.

The product should feel like a **premium enterprise operating system**, not a template.

## CORE DESIGN PHILOSOPHY

Create a visual identity that is:

* Elegant
* Minimal
* Professional
* Intelligent
* Calm
* Sophisticated
* Timeless
* Industry-neutral
* Highly usable
* Executive-friendly

DO NOT use:

* Black-heavy UI
* Purple AI-dashboard aesthetics
* Neon colors
* Cyberpunk styling
* Excessive gradients
* Excessive glassmorphism
* Gaming-style UI
* Cartoon illustrations
* Excessive rounded cards
* Huge colorful icons
* Generic startup landing-page aesthetics
* Typical blue/purple SaaS dashboard styling

The interface should look like a serious enterprise product used by executives, administrators, HR managers and operations teams.

## VISUAL SYSTEM

Use a refined neutral visual language.

Primary surfaces:

* Warm off-white / ivory
* Soft stone
* Very light neutral gray

Primary text:

* Deep charcoal / graphite

Secondary text:

* Muted gray

Borders:

* Extremely subtle neutral borders

Accent:

* Use ONE restrained sophisticated accent color for interactive states and important actions.
* The accent must be muted and elegant rather than bright.
* Avoid making the entire interface colorful.

Status colors should be reserved strictly for meaning:

Success → subtle green
Warning → muted amber
Critical → restrained red
Information → muted neutral accent

Colors should communicate meaning, not decoration.
